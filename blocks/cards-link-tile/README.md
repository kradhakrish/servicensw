# cards-link-tile

Custom **cards** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. One row per tile, one cell: a linked heading (h3) and an optional description paragraph. The whole tile is clickable through the heading link.

## Supported variations

- default: navy-top-bar tiles with shadow and arrow; 1-up, 2-up from 480px, 3-up from 1024px.
- `ghost`: title-only "Related information" tiles (taller line height, lower min-height); 4-up from 1024px.
