# hero-banner

Custom **hero** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one column, two rows:

1. Background image (the photo behind the title).
2. Heading (H1) and a subtitle paragraph.

Either row may be omitted: with no image the block becomes a plain title area, and with no text it becomes a 4:1 photo strip.

## Supported variations

No variations.
