# table

Custom **table** block. 

## Authoring (Document Authoring)

Model: `table`

Each block row is a table row and each cell is a table cell. The first row is the header row unless the `no-header` option is set. Inline formatting and links are kept. A row with fewer cells than the widest row stretches its last cell across the remaining columns.

## Supported variations

| Variation | Option class |
| --- | --- |
| No header row | `no-header` |
| Striped rows | `striped` |
